# Claude Session Log - 20260511225925

## Task
Fix login email validation to allow underscore `_` in domain part (e.g. `admin@seed_demo.local`).

## Root Cause
Both login forms use `{ type: 'email' }` rule from Ant Design (async-validator), which rejects underscores in domain names per strict RFC 5321 — but local/dev environments commonly use them.

## Files to Fix
- `frontend/src/platform/pages/Login.jsx` line 30
- `frontend/src/tenant/pages/Login.jsx` line 34

## Fix
Replace `{ required: true, type: 'email' }` with a custom pattern rule that allows underscores in domain names.

## Status: Done

## Result
Replaced `type: 'email'` with custom pattern `/^[^\s@]+@[^\s@.]+(\.[^\s@.]+)+$/` in both files.
Pattern allows underscores anywhere, requires one `@` and at least one `.` after the `@`.
